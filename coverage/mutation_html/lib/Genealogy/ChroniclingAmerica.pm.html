   56: =head1 DESCRIPTION
   57: 
   58: The B<Genealogy::ChroniclingAmerica> module allows users to search for historical newspaper records from the B<Chronicling America> archive,
   59: maintained by the Library of Congress.
   60: By providing a person's first name,
   61: last name,
   62: and state,
   63: the module constructs and executes search queries,
   64: retrieving URLs to relevant newspaper pages in JSON format.
   65: It supports additional filters like date of birth and date of death,
   66: enforces B<rate-limiting> to comply with API request limits,
   67: local caching,
   68: and includes robust error handling and validation.
   69: Ideal for genealogy research,
   70: this module streamlines access to historical newspaper archives with an easy-to-use interface.
   71: 
   72: =over 4
   73: 
   74: =item * Rate-Limiting
   75: 
   76: A minimum interval between successive API calls can be enforced to ensure that the API is not overwhelmed and to comply with any request throttling requirements.
   77: 
   78: Rate-limiting is implemented using L<Time::HiRes>.
   79: A minimum interval between API
   80: calls can be specified via the C<min_interval> parameter in the constructor.
   81: Before making an API call,
   82: the module checks how much time has elapsed since the
   83: last request and,
   84: if necessary,
   85: sleeps for the remaining time.
